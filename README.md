# Прототип главной страницы «Мед-ЭКСПРЕСС»

Статический адаптивный UX-прототип на HTML, CSS и JavaScript. Выполнен в чёрно-белом формате без фотографий, иконок, фирменных цветов и декоративных элементов. Будущие визуальные материалы обозначены серыми подписанными плашками.

Главная построена по утверждённой структуре: первый экран, о клинике, услуги, врачи, популярные цены, преимущества и оборудование, отзывы, контакты с картой и формой записи.

Ссылки в меню, карточках и подвале уже показывают будущую структуру многостраничного сайта. Внутренние страницы будут добавлены на следующих этапах.

## Просмотр

Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер в этой папке.

## Что требуется заменить перед финальной сборкой

- логотип в векторном формате;
- оригинальные фотографии клиники, оборудования и врачей;
- актуальные цены;
- подтверждённые отзывы;
- лицензия и реквизиты;
- финальная интеграция онлайн-записи.
